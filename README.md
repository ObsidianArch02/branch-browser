# Branch

一个可运行的文件目录浏览器复刻，参考 [Conrad Barski 的视频](https://x.com/lisperati/status/2104681013909893184)。

保留原视频中的黑底等宽文字、向右分叉的目录、圆角直角连线和多个子目录同时预览。默认是与视频相似的示例文件，可以打开自己的本地文件夹。布局由 D3 flextree 计算。这是根据视频重建的交互原型，没有使用原作者的源码。

## 运行

```sh
npm install
npm run dev -- --host 127.0.0.1 --port 5173
```

## 操作

- 单击文件夹进入目录；单击文件选中，双击预览。预览打开时保留文件名行及其选中状态；从列表打开文件也会进入画布预览。
- 方向键上下选择项目；右方向键进入目录；Enter 打开；空格预览。预览打开时，左方向键、Backspace 或 Esc 先关闭预览并停留在该文件；关闭后再按左方向键返回上级。退出目录（包括空文件夹）时保留该目录的选中状态，右方向键可重新进入。预览打开后，选择其他文件可直接切换内容。
- 当前选中项始终居中，打开文件时预览成为焦点。滚轮以中央焦点缩放；拖动空白区域或预览标题可临时平移，松开后恢复居中；触屏双指缩放。预览内容内的滚轮用于阅读，Ctrl/Cmd + 滚轮仍可缩放。
- 底部按钮支持缩放和适应全部目录；点击缩略图也可适应全部。
- 搜索按文件名匹配；Ctrl/Cmd + F 或 / 聚焦搜索。打开本地目录后，搜索会逐步读取子目录。
- 显示设置可以开关子目录预览、隐藏文件，调整字号和间距，或返回示例。

## 本地文件

Chrome 等支持 File System Access API 的浏览器使用只读文件夹权限。其他浏览器使用文件夹选择器；该降级方式无法列出空文件夹。文件在浏览器内读取，不上传，不修改磁盘上的内容。文本预览最多显示前 512 KB。示例中部分二进制文件仅有文件名；`build/browser-preview.png` 包含原视频的参考帧。

## 验证

```sh
npm test
npm run build
```

构建结果在 `dist/`。使用 `npm run preview` 可以本地预览构建结果。
